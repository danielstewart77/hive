Curation

Rules run in order and write a verdict onto every row. Nothing is deleted, so a changed policy can be re-applied to the whole corpus.

Scheduled skills fire on a timer, so their turns are near-identical. One discards genuine variety in a recurring task; unbounded lets a single alert skill drown out every hand-written session.
Off by default: export redacts every credential regardless, and the underlying turn is usually a good demonstration of tool use.

Export

Renders kept turns to train.jsonl and eval.jsonl. Credentials are always redacted; the split is by session so an eval score cannot measure memorization.

Fine-tune

A LoRA run takes the whole GPU, so it is described and checked before it is started. Planning is always safe.

Once an adapter is trained and served, point a mind at it from that mind's page under Minds — the default-model editor there is what actually switches a mind over.
