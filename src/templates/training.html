Model training

Training

Every turn each mind takes is captured raw. Curation decides which of them should reach a trainer, export renders them as a dataset, fine-tuning turns that dataset into an adapter, and deploy puts the adapter in front of a mind. Four stages, in that order — each one only sees what the stage before it produced.

1 · Curation

Rules run in order and write a verdict onto every row. Nothing is deleted, so a changed policy can be re-applied to the whole corpus at any time.

2 · Export

Renders the kept turns into train.jsonl and eval.jsonl. The split is by session, never by turn, so an eval score cannot be measuring memorization of a session the model already trained on.

3 · Fine-tune

Trains a LoRA adapter: a few hundred megabytes of weight deltas that ride on top of an existing model rather than replacing it. A run takes the whole GPU, so it is described and checked before it is started.
