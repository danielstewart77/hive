Harness runs

Each run is one dispatch driven as a goal: the harness re-enters the model at every idle checkpoint until the work is done or the round cap runs out. What is measured is the tool traffic — calls the model emitted, calls the harness could serve, and the names and argument spellings it refused. A refused call is the worklist: the harness grows a tool matching the call.
